## 🚀 Rodando localmente

Não precisa de nada além de um navegador:

```bash
git clone https://github.com/DiamanteBlackOfc/QGoficialLapidado-.git
cd QGoficialLapidado-
```

Abre o `index.html` direto no navegador, ou serve local com:

```bash
python3 -m http.server 8000
```

---

## 🌐 Deploy (GitHub Pages)

1. Vá em **Settings** → **Pages** no repositório.
2. Em **Source**, selecione a branch `main` e a pasta `/root`.
3. Salve. O site fica no ar em:

```
https://diamanteblackofc.github.io/QGoficialLapidado-/
```

Gratuito, com HTTPS automático, 24/7 no ar.
